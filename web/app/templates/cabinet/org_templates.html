Загрузить шаблон

Если это договор для мастера «Комплект», выберите тип контрагента. Иначе шаблон будет только в списке одиночной генерации.

Как подготовить

В DOCX используйте поля: {{ '{{ номер_договора }}' }}, {{ '{{ дата_договора }}' }} и фильтры (| руб, | прописью). Конструкции {{ '{%' }} … {{ '%}' }} и макросы VBA запрещены.

Нужно своё поле? Впишите {{ '{{ имя_поля }}' }} в DOCX (строчные буквы и «_», без точек) — при загрузке сервис покажет список «Новые» и попросит задать подпись и тип. Либо заранее создайте поле в разделе Поля.

После сохранения заполняйте документ через Документы → «Заполнить»: свои поля будут в блоке «Поля организации». Пошаговая инструкция — в Как пользоваться.

Общие шаблоны сервиса по-прежнему доступны всем; ваши хранятся только в вашей организации.
