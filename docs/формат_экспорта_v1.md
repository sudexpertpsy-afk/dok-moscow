# Формат выгрузки организации `dok-export-v1`

Выгрузка: **Настройки → Данные организации → Выгрузить всё**.
Архив собирается фоновой задачей, лежит в `FILES_ROOT/{org_id}/exports/`,
скачивание авторизованное, TTL 24 часа. Импорт архива обратно в сервис
**вне скоупа** — формат зафиксирован, чтобы данные были переносимы.

## Имя файла

`dok-export_{название_орг}_{ГГГГ-ММ-ДД}.zip`

## Структура

```
README.txt
manifest.json          # format, exported_at, org_id, counts
organization.json      # id, name, requisites (без секретов)
users.json + users.csv # email, роли, статусы (без хэшей/TOTP-секретов)
counterparties.xlsx + counterparties.json
contracts.xlsx + contracts.json
documents.xlsx + documents.json   # + archive_path
files/documents/…                 # DOCX/PDF
templates_org/                    # свои шаблоны DOCX + манифесты
fields.json
branding/                         # печать/подписи
numbering.json                    # счётчики
calendar.json
law_bookmarks_notes.json
payments.xlsx + payments.json     # без raw_events / карт
events.csv
```

## Правила

- Таблицы: XLSX (для людей) + JSON (для машин).
- Значения с ведущими `= + - @` экранируются префиксом `'` (formula injection).
- В архиве только данные своей `org_id`; пользователи — только этой org.
- Секреты (пароли, TOTP, ключи API, Fernet) не включаются.
- `manifest.counts.document_files` — сколько файлов реально попало в `files/`.

## Версионирование

Поле `manifest.format` = `dok-export-v1`. При несовместимых изменениях
увеличивать минор/мажор и обновлять этот документ.
