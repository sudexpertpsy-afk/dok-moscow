# Источники НПА для раздела «Законодательство»

Рабочий пакет W-17 · проверено агентом Cursor 1 августа 2026 г.

Базовый принцип: тексты и редакции — **только** из государственных источников
(п. 6 ст. 1259 ГК РФ; без КонсультантПлюс/Гарант).

## 1. Официальное опубликование — `publication.pravo.gov.ru`

Открытый JSON-API (режим чтения). Справка: <http://publication.pravo.gov.ru/help>.

**Важно:** в части сетей HTTPS обрывается; рабочий базовый URL —
`http://publication.pravo.gov.ru` (как в клиентах сообщества). HTTPS оставляем
как опцию через `PRAVO_PUBLICATION_BASE`.

### Эндпойнты (проверены)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/DocumentTypes` | справочник видов документов |
| GET | `/api/SignatoryAuthorities` | принявшие органы |
| GET | `/api/PublicBlocks` | блоки публикации |
| GET | `/api/Categories?block=…` | категории органов |
| GET | `/api/Documents` | поиск НПА |
| GET | `/api/Document?eoNumber=…` | карточка документа |
| GET | `/api/DocumentText?eoNumber=…` | признак наличия текста (`true`/`false`) |
| GET | `/file/pdf?eoNumber=…` | PDF официальной публикации |

### `/api/Documents` — параметры (фрагмент)

- `PageSize`: **только** `10`, `30`, `100`, `200`
- `Index`: номер страницы (с 1)
- `Name`, `Number`, `NumberSearchType` (0 точно / 1 начинается / 2 заканчивается / 3 содержит)
- `PeriodType`: `daily` \| `weekly` \| `monthly` \| `day` (+ `Date`)
- `PublishDateFrom` / `PublishDateTo`, `DocumentDateFrom` / `DocumentDateTo`
- `DocumentTypeId`, `SignatoryAuthorityId`, `Block`, `EoNumber`

Пример PDF: `http://publication.pravo.gov.ru/file/pdf?eoNumber=0001202407220006`

### Вежливый режим клиента

- User-Agent: `DokMoscowBot/1.0 (+https://dok.moscow; legal@dok.moscow)`
- не более **1 запроса/сек**
- кэш GET в памяти (TTL настраивается)

## 2. ИПС «Законодательство России» — актуальные редакции

Публичный HTML-интерфейс: `http://pravo.gov.ru/proxy/ips/`.

Программный JSON-API поиска нестабилен (форма `start_search` требует сессионных
полей). Для загрузки текста используем прямой доступ по внутреннему `nd`:

```
GET http://pravo.gov.ru/proxy/ips/?doc_itself=&nd=<ND>&page=1&rdk=<RDK>&link_id=0
```

- кодировка ответа: **windows-1251**
- текст: блок `.doc_content`
- `rdk` пустой или максимальный — действующая редакция; `rdk=0` — исходная

Дополнительно: подсистема актуальных текстов `http://actual.pravo.gov.ru`
(`HTTP_HOST = http://actual.pravo.gov.ru:8000/api/ebpi/`, метод `redtext`) —
запасной канал; в W-17 основной путь — `doc_itself` по `ips_nd`.

### Известные `nd` начального реестра

| Акт | ips_nd |
|-----|--------|
| 73-ФЗ о ГСЭД | `102071320` |
| ГПК РФ | `102078828` |
| АПК РФ | `102079219` |

Остальные `nd` уточняются при наполнении (W-18/владелец).

## 3. Мониторинг (схема)

1. Ежедневно для актов с `watch_enabled` — поиск в `/api/Documents` по
   `watch_name` (и/или номеру) за период с прошлой проверки.
2. Новые `eoNumber`, похожие на изменяющие акты → запись в `act_watch_log`,
   попытка подтянуть текст из ИПС, черновик `act_versions` + diff, письмо
   администратору.
3. Ошибка источника → `source_error` в журнале; 3 подряд — отдельное письмо.

Публикация черновика — только вручную (W-19).
