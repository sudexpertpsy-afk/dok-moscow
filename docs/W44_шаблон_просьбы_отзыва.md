# Шаблон просьбы об отзыве (W-44, волна 3)

Отзывы на лендинг публикуются **только** через слоты Единого окна
(`review_1_*` … `review_3_*`). Без реальных ответов блок на главной скрыт —
выдуманные цитаты не использовать.

## Письмо бета-пользователю

Тема: Короткий отзыв о Док.Москва (3 вопроса)

Здравствуйте!

Мы собираем первые отзывы для страницы dok.moscow. Если удобно — ответьте
тремя фразами (можно голосовым или в ответ на это письмо):

1. **Что делали до** Док.Москва с договорами / счетами / заключениями?
2. **Что изменилось** после того, как начали пользоваться кабинетом?
3. **Кому посоветуете** сервис (роль / тип практики)?

Если можно указать имя (или инициалы) и кратко регалии для публикации
(например: «судебный эксперт, стаж 12 лет») — напишите, как подписать отзыв.
Если публикация без имени — тоже нормально, согласуем формулировку.

Спасибо!
