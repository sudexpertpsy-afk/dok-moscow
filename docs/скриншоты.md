# Чек-лист скриншотов кабинета для лендинга (W-37)

Обезличенные кадры демо-организации для `web/app/static/img/`.

## Подготовка

1. Организация: **«Экспертный центр Пример»** (или аналог без реальных ПДн клиентов).
2. Тема: светлая.
3. Окно браузера: **1440×900** (или 1280×800 — допустимо для CI/моков).
4. Данные: вымышленные ИНН/ФИО/номера договоров; без печати личных данных сотрудников.

## Файлы

| Файл | Экран |
|------|--------|
| `hero-app.webp` | Мастер комплекта, **шаг 2** (состав: договор / счёт / акт / ПКО) |
| `how-step1.webp` | Карточка заказчика / ввод ИНН → ЕГРЮЛ |
| `how-step2.webp` | Тот же шаг 2 комплекта (можно кроп от hero) |
| `how-step3.webp` | Готовый комплект: скачивание DOCX / PDF |

Формат: WebP, задать `width`/`height` в разметке (без CLS). Hero — `fetchpriority="high"`; шаги — `loading="lazy"`.

## Миниатюры PDF

После `python scripts/make_samples.py` (или `--thumbs-only`):

- `sample-dogovor.webp`
- `sample-schet.webp`
- `sample-akt.webp`

из первой страницы соответствующих PDF в `static/samples/`.
