# Сервер из админки (W-34)

Раздел `/admin/server/` для `service_admin`. Управление идёт через контейнер
**ops-agent** во внутренней сети Docker Compose: порт наружу не публикуется,
вызовы только с Bearer `OPS_AGENT_TOKEN` (≥ 32 байт).

## Что можно из админки

| Действие | Условие |
|----------|---------|
| Смотреть статус (CPU/RAM/диск, контейнеры, git, SSL, бэкап) | `OPS_AGENT_ENABLED` + токен |
| Хвост логов app/worker/caddy/gotenberg; postgres — только error | то же; строки маскируются |
| Restart app / worker / caddy / gotenberg | 2FA + слово `RESTART` |
| Redeploy (ветка/тег → `deploy/ops_redeploy.sh`) | 2FA + `REDEPLOY` |
| Внеплановый бэкап и скачивание архивов | 2FA (бэкап) |
| Reload / restart Caddy (сертификат) | 2FA |
| Ссылки Hostland и дата оплаты VDS | всегда (файл `.ops/hostland.json`) |

Все изменяющие действия пишутся в `events` (`ops_*`) и таблицу `ops_journal`.

## За чем идти в Hostland

- Оплата и продление VDS (сервис напомнит письмом за 14 и 3 дня).
- Переустановка ОС.
- Аварийная веб-консоль, если Docker/приложение полностью недоступны.

## Включение на проде

В `deploy/.env`:

```env
OPS_AGENT_ENABLED=true
OPS_AGENT_URL=http://ops-agent:9100
OPS_AGENT_TOKEN=<openssl rand -base64 48>
```

Затем `./deploy/deploy.sh` (собирает и поднимает `ops-agent`).

## Безопасность

- Нет произвольного shell и чтения произвольных файлов — только белый список
  эндпойнтов `/v1/*` (см. `app.ops_agent.WHITELIST_ACTIONS`).
- Postgres нельзя перезапустить из UI.
- Rate limit на агенте; без токена — 401.
